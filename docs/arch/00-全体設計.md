# 1. 目的

このサービスは、ユーザーが管理するデバイスの現在IPアドレスを受け取り、
外部DNSサーバへA/AAAAレコードとして反映するDDNS管理サービスである。

また、APIを通じてデバイスの現在IPアドレスを参照可能にする。

# 2. 要求
## 2.1 機能要求
- デバイスから現在IPアドレスの通知を受け付ける
- デバイスとIPv4/IPv6アドレスの関連を管理する
- IPv4アドレスをAレコードとして外部DNSサーバへ反映する
- IPv6アドレスをAAAAレコードとして外部DNSサーバへ反映する
- APIでデバイスの現在IPアドレスを提供する
- アクセスキーによりAPIアクセスを認証・認可する

## 2.2 非機能要求
- アクセスキーは平文保存しない
- DNS反映失敗時に再試行できる
- アドレス更新履歴を監査可能にする
- 同一IPへの連続更新では不要なDNS反映を避ける
- IPv4のみ、IPv6のみの環境に対応する

- デバイスからの通知受けアドレスを取得する
- デバイスと(IP|IPv6)アドレスの関連を管理する
- 外部のDDNSサーバに対して、デバイスの現在アドレスをA/AAAAレコードとして反映する
- APIでデバイスのIPアドレスを提供する

# 3. システム概要

本サービスは、デバイスまたはクライアントからのアドレス更新要求を受け付け、
認証・認可を行ったうえでデバイスの現在アドレスを更新する。

現在アドレスが変更された場合、紐づくホスト名に対してDNS同期を要求する。
DNS同期処理は、デバイスの現在アドレスをA/AAAAレコードとして外部DNSサーバへ反映する。

# 4. ドメインモデル

## 4.1 ユーザー

### 概要

このサービスを利用する人間または管理主体。

### 関連

- 複数のデバイスを所有できる
- 複数のコントロールグループを作成・管理できる
- アクセスキーを発行・失効できる

### 制約

- ユーザーは自分が所有するリソースのみ管理できる

## 4.2 デバイス

### 概要

ユーザーが管理する端末またはネットワーク上の対象。
IPアドレスを通知する主体である。

### 関連

- 1ユーザーに所有される
- IPv4アドレス、IPv6アドレスを持てる
- 複数のコントロールグループに所属できる
- 0個以上のホスト名に紐づけられる

### 制約

- disabled または deleted のデバイスはアドレス更新できない

## 4.3 アドレス

### 概要

デバイスに紐づく現在のIPアドレス。
IPv4またはIPv6であり、IPv4はAレコード、IPv6はAAAAレコードに対応する。

### 方針

- 現在値と更新履歴を分けて管理する
- 通知日時を記録する
- 通知元アドレスを記録する
- DNS反映状態とは分離する

## 4.4 ホスト名

### 概要

DNS上で公開する名前。
1つのデバイスに紐づき、デバイスの現在アドレスをA/AAAAレコードとして公開する。

### 制約

- FQDNはDNSゾーン内で一意とする
- A/AAAAの公開可否を設定できる

## 4.5 コントロールグループ

### 概要

デバイスへのアクセス権限をまとめる単位。

### 関連

- ユーザーが作成・管理する
- 複数のデバイスを含めることができる
- デバイスは複数のコントロールグループに所属できる
- グループ単位のアクセスキーを発行できる

## 4.6 アクセスキー

### 概要

APIにアクセスするための認証情報。

### 方針

- 単一の対象リソースに紐づく
- 対象リソースはコントロールグループまたはデバイスのいずれか
- 複数の対象リソースには紐づかない
- 権限スコープを持つ
- 有効期限を持つ
- 明示的に失効できる
- 平文保存しない
- 発行後にキー値は再表示しない

## 4.7 権限スコープ

| スコープ | 説明 |
|---|---|
| read | 対象リソースの情報を参照できる |
| update_address | 対象デバイスの現在アドレスを更新できる |
| manage_device | デバイス設定を変更できる |
| manage_group | グループ設定と所属を変更できる |
| manage_access_key | アクセスキーを発行・失効できる |

# 5. アドレス更新設計

## 概念整理

### ユーザー

- このサービスを利用する人間
- 複数のデバイスを所有できる
- 複数のコントロールグループを作成・管理できる
- アクセスキーを発行・失効できる

### デバイス

- ユーザーが管理する端末またはネットワーク上の対象
- IPアドレスを通知する主体
- IPv4アドレス、IPv6アドレスを持てる
- 複数のコントロールグループに所属できる
- 1つ以上のホスト名に紐づけられる

### アドレス

- デバイスに紐づく現在のIPアドレス
- IPv4またはIPv6である
- IPv4はAレコード、IPv6はAAAAレコードに対応する
- 通知日時を持つ
- 必要に応じて通知元アドレスや反映状態を持つ

### ホスト名

- DNS上で公開する名前
- 1つのデバイスに紐づく
- デバイスの現在アドレスをA/AAAAレコードとして公開する

### コントロールグループ

- デバイスへのアクセス権限をまとめる単位
- ユーザーが作成・管理する
- 複数のデバイスを含む
- デバイスは複数のコントロールグループに所属できる
- グループ単位のアクセスキーを発行できる

### アクセスキー

- APIにアクセスするための認証情報
- 単一の対象リソースに紐づく
- 対象リソースはコントロールグループまたはデバイスのいずれか
- 複数の対象リソースには紐づかない
- 権限スコープを持つ
- 有効期限を持ち、期限切れ後は無効になる
- 明示的に失効できる
- 期限切れまたは失効後は、新しいアクセスキーを発行できる

### 権限スコープ

- read
  - 対象リソースの情報を参照できる
- update_address
  - 対象デバイスの現在アドレスを更新できる
  - 対象がコントロールグループの場合、グループに含まれるデバイスの現在アドレスを更新できる
- manage
  - 対象リソースの設定変更、所属変更、アクセスキー管理を行える
